# SEEEX Console 页面与组件详细规格

## 1. 统一页面状态

所有页面必须处理：loading、empty、error、forbidden、readonly、dirty、saving、success。

## 2. 统一数据交互

Table 页面必须具备服务端分页、服务端筛选、排序或明确默认排序、行选择、批量确认、行级权限、空状态、加载状态、失败重试、重点业务字段、详情入口，并保存 URL 筛选和分页状态。

Drawer 页面必须具备查看/新增/编辑模式、关闭前未保存确认、字段校验、关联对象选择器、保存中状态、保存后刷新、服务端字段错误和只读模式。

## 3. 登录页

功能：本地账号登录、企业微信登录、登录失败、账号停用、无权限、登录态恢复、退出登录。

组件：BrandPanel、LoginForm、WecomLoginButton、LoginErrorAlert。

关键参数：loginMode、loading、error、onSubmit、onWecomLogin、redirectPath。

## 4. 主布局和应用导航

功能：SEEEX Logo、工作台、系统平台、应用中心、应用切换、树形菜单、当前菜单高亮、面包屑、用户菜单、退出和响应式折叠。

组件：AppShell、TopBar、SideNavigation、ApplicationSwitcher、Breadcrumbs、UserMenu。

关键参数：applications、activeApplication、navigationTree、selectedPath、collapsed、permissions、onApplicationChange、onCollapse、onLogout。

## 5. 工作台

内容：常用应用、最近访问、待处理事项、同步状态、系统公告、快捷操作、当前用户权限摘要。

组件：ApplicationCard、RecentAccessList、TodoCard、SystemStatusCard、PermissionSummary。

## 6. 员工管理

重点字段：工号、姓名、手机号、邮箱、所属部门名称、职级名称、状态、企业微信状态、角色数量、直接权限数量、最近登录时间。

操作：新增、编辑、详情、启用/停用、软删除、批量停用、角色管理、直接权限、最终权限分析、权限来源、审计。

关联选择：部门使用远程 TreeSelect，职级使用远程 Select，角色使用远程多选，权限使用应用资源树。禁止手填 ID。

## 7. 部门管理

形态：左侧部门树，右侧详情和员工列表。

操作：新增根部门、新增子部门、编辑、移动、负责人、员工列表、绑定角色、继承权限、启停、企业微信同步。

## 8. 职级管理

字段：职级名称、编码、等级值、员工数量、默认角色数、企业微信映射、状态。

操作：新增、编辑、详情、默认角色、企业微信职位映射、关联员工、权限分析。

## 9. 角色管理

字段：角色名称、编码、所属应用、角色类型、人员数量、部门数量、职级数量、权限数量、状态。

操作：新增、编辑、详情、配置资源、绑定人员/部门/职级、复制、停用、删除、审计。

资源配置使用应用/模块资源树，支持 ALLOW/DENY、继承标记、搜索、节点全选和保存前差异预览。

## 10. 资源管理

形态：资源树加详情抽屉。

类型：APPLICATION、MODULE、PAGE、MENU、ACTION、API、DATA_SCOPE。

字段：名称、编码、权限编码、类型、所属应用、父资源、路由、图标、排序、是否菜单、是否公开、状态。

操作：新增子资源、编辑、移动、排序、复制、停用、删除、查看绑定角色。

## 11. 人员权限分析

流程：选择人员 → 加载组织关系 → 加载角色绑定 → 加载直接授权 → 计算最终权限 → 展示来源和覆盖原因。

分区：人员摘要、组织关系、角色来源、直接授权、允许权限、拒绝权限、最终权限、冲突分析。

## 12. 应用中心

应用卡片展示 Logo、名称、描述、类型、状态、授权状态、最近访问和入口。

应用详情使用 Tabs：概览、资源、成员、权限、版本、认证、审计。

## 13. 企业微信

配置页：配置状态、脱敏 CorpID、AgentID、回调地址、连接检查、登录开关。

同步页：批次、时间、数量、成功/失败、错误、重试、差异预览。

事件页：事件类型、时间、处理状态、幂等号、错误、重试；原始数据仅审计权限可见。

## 14. 文件中心

形态：左侧目录树，右侧文件表格。

功能：上传、进度、类型筛选、状态筛选、下载、删除、批量删除、详情、权限来源、空间容量。

## 15. 审计日志

字段：操作时间、操作人、操作类型、对象类型、对象名称、来源 IP、结果、变更摘要。

操作：筛选、详情、导出、按对象追踪、按操作人追踪。

## 16. 自评清单

每个页面完成后检查：无 JSON 详情、无 ID 手填、真实空状态、失败重试、保存防重复、未保存提醒、行级权限、批量确认、服务端分页、重点字段、列表到详情再返回、新增到刷新、删除到刷新、权限来源、无假成功提示、无前端伪造权限、刷新后恢复筛选分页。
